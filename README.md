# 对拍

中文名：**对拍** · 前缀 `duet` · 端口 **7800**

## 骨架（新骨，不是闸对/缝包换皮）

**左轨装载 → 右轨装载 → 同键对齐落差 → 单边悬账 → 对拍结论**

| 对比 | 闸对 | 缝包（已弃） | **对本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→在途→成物 | 单流入→在途→成物 | **双轨独立装载→键对齐** |
| 在途态 | 开腿账 | 拼缝账 | **无开腿/拼缝；悬账是对齐后单边** |
| 产物 | 行程账 | 整件账 | **对齐差 + 对拍结论** |
| 旁路名 | 旁路匣 | 旁路匣 | **悬账单（命名与语义都不同）** |

皮：支付渠道回执 vs 核心记账。去皮：**双源键对齐管道**。禁止做成收银 CRUD、报表看板、工单系统。

## 日界切开禁跨（已落主链路）

流水按「业务键 + 业务日（事件时 UTC 日期）」归组后再编排对齐，独立于基线 happy path：

- 同日双边 → 对齐差（带左/右业务日，`跨日=0`）。
- 跨日同键二择一（轨规键 `日界跨日策略`）：
  - **禁跨**（默认）：不写双边对齐差；两侧各写一张 `日界旁路凭证` 钉跨日，悬账由凭证背书，结论改读旁路集。
  - **打标**：仍写对齐差并置 `跨日=1`、记左右业务日，不写禁跨旁路，读引用差行。
- 切日编排与基线「跑对齐」共用 `对齐锁`，并发只准一个落库，抢锁失败返回 409，绝不双落；异常必放锁。
- 接口：`POST /api/日界/跑`、`GET /api/日界`（差与旁路统一只读视图，含业务键/左日/右日/差或旁路/valid）、`GET /api/日界?键=`（单键形态区分）、`GET|POST /api/日界策略`。
